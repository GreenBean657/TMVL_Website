# Introduction
This is a website for a fictional site for a SCP style containment
facility called AEGIS, who stores entities "AEGs". 

# Theme
white, light-gray, cyan-teal, a lot of hexagon patterns with their logo

# Site Style
This facility uses a site style similar to SCP (https://scp-wiki.wikidot.com/scp-series), but in the aforementioned theme.
AEGIS includes character cards as well, for the roleplayed characters in the complex.
